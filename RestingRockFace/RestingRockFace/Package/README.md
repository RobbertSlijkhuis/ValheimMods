# Resting Rock Face

A simple mod that allows you to set a specific face to your Rockies! Building a Rocky village or a scene? Open the "Rename" window and you can set its name and face!

![rocky friend got hurt scene](https://robhost.nl/img/valheim/resting_rock_face.jpg)
![rocky picnic scene](https://robhost.nl/img/valheim/rocky_picnic_scene.jpg)
![resting rock face gui](https://robhost.nl/img/valheim/rocky_gui.jpg)
