# Plant Cart

A mod that lets you plant crops using a cart! Load it with seeds or crops, and it will automatically plant them in cultivated soil as you move.

Designed to make planting faster and more convenient—similar to how the scythe speeds up harvesting. Includes a custom model with multiple load and damage states, along with a unique material that can be purchased from a trader.

## Config

### Plant Cart
- **Enable**: Whether the Plant Cart can be built. Default: **true**
- **Name**: The display name of the cart. Default: **Plant Cart**
- **Description**: The in-game description of the cart. Default: **Plant crops effortlessly with a cart that sows seeds as you go.**
- **Crafting Station**: The station required to craft the cart. Default: **Workbench**
- **Recipe**: The resources required to craft the cart. Default: **Wood:20, Copper:6, Silver:10, Plow_PC:2**
- **Inventory Columns**: Number of columns (width) in the cart's inventory. Default: **3**
- **Inventory Rows**: Number of rows (height) in the cart's inventory. Default: **1**
- **Cart Mass**: The weight of the cart, affecting speed and handling. Default: **300**
- **Durability Loss**: Durability lost per planting action. Default: **1**

### Rusted Plow
- **Name**: The display name of the item. Default: **Rusted Plow**
- **Description**: The in-game description of the item. Default: **An old, rusted plow, perhaps it can be restored and used for something.**
- **Teleportable**: Whether the item can be teleported. Default: **false**
- **Trader**: The trader who sells this item. Default: **Haldor**
- **Cost**: The price of the item at the trader. Default: **300**
- **Stack**: The stack size when purchased from the trader. Default: **1**
- **Global Key**: The required global key for this item to appear at the trader (boss defeated). Default: **defeated_dragon (Moder)**
