# Grappling Harpoon Hook

This small mod turns the **Grappling Hook** into a harpoon as well! Its secondary attack now acts like the **Abyssal Harpoon**, allowing you to latch onto creatures and move/pull them. To make it a bit more balanced (since it now fulfills two roles) you still need to reload the Grappling hook before you can shoot again.
