# Remove Ashlands Heat Haze

A small mod that removes the screen-wide heat-distortion VFX shown during Ashlands weather (see
screenshot). It's a purely client-side visual suppression - no server requirement, no
gameplay changes. The effect is disabled automatically whenever the mod is active; there's no
configuration.

![Heat haze](https://robhost.nl/img/valheim/removeashlandsheathaze/AshlandsHaze.png)

I made this for a dear friend, KassieTheLittlePumpkin, who actually gets migraines from the
effect. Hope this helps, Kassie!
